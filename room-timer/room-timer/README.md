# 룸 타이머 보드 (101호~118호)

여러 명이 동시에 보고 시간을 넣고 빼는 노래방 룸 타이머. 빌드 과정 없는 정적 사이트입니다.

## 1. Firebase 만들기 (무료, 5분) — 여러 기기 실시간 공유용
1. https://console.firebase.google.com → 프로젝트 추가
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기** (위치: 싱가포르 권장, "잠금 모드"로 시작)
3. Realtime Database → **규칙** 탭에 `database.rules.json` 내용을 그대로 붙여넣고 **게시**
4. 프로젝트 설정(톱니바퀴) → 내 앱 → **웹 앱(</>) 추가** → 나오는 `firebaseConfig` 값을 `firebase-config.js` 에 붙여넣기
   (`databaseURL` 이 반드시 들어 있어야 합니다)

## 2. GitHub + Vercel 배포
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 전부 올립니다.
2. https://vercel.com → Add New → Project → 그 저장소 Import → 설정 변경 없이 **Deploy**
3. 나온 주소를 실장님들에게 공유하면 끝. 이후 GitHub에 올리면 자동으로 다시 배포됩니다.

## 사용법
- 방을 누르면 노란 테두리로 선택 → 아래 버튼으로 시간 추가/차감
- 5분 남으면 방이 빨간색으로 바뀌고(연장 체크), 시간이 끝나면 **시간종료**로 깜빡입니다. 종료된 방에 시간을 넣으면 지난 시간만큼 빠져서 들어갑니다 (종료 6분 뒤 +50분 → 44분)
- **입실대기**(초록) / **퇴실대기**(주황): 한 번 누르면 표시, 다시 누르면 해제. 시간을 넣으면 자동 해제
- 퇴실대기를 누르면 그 방의 타이머는 지워지고 주황 "퇴실대기"만 표시됩니다
- 시간은 분 단위(올림)로 표시됩니다
- **퇴실**: 방을 빈방으로 초기화
- 🔔 소리: 기기마다 한 번 눌러 켜면 5분 남았을 때·종료 시 알림음 (화면이 켜져 있을 때)

## 설정 바꾸기
- 방 이름: `logic.js` 의 `roomLabel` (예: `n + '번방'`)
- 빨간색·알림 시점: `logic.js` 의 `WARN_SECS`
